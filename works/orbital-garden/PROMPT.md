# 创作记录与复用 Prompt

## 本次实际输入

用户说明希望将新 fork 的仓库扩展为 GPT-6 Astra 优质作品清单，之后发布到个人官网，并提出：

> 我现在用的就是 GPT-6 Astra ultra，你帮我生成一个有创意的优质作品。

模型据此提出并实现「轨道花园」。下方详细 Prompt 是**根据最终成品整理的复用版本**，不是本次的原始完整输入；不暗示相同 Prompt 能确定性复现同样的结果。

## 复用版本

```text
请创作一件原创、完整、可直接放上个人官网的浏览器交互艺术作品：
ORBITAL GARDEN / 轨道花园。

创意：如果引力也有生命，它会开出怎样的花？让一群光点在秩序与混沌
之间生长。作品一打开就呈现可交互雕塑，不要先显示营销页或开始按钮。

视觉：深色艺术展厅，精细的薄荷绿发光粒子，优雅的大号衬线英文标题，
克制的中文说明、细分隔线和展品编号。画面中心是一件有体积和层次的
光点雕塑。配色随形态在薄荷绿、琥珀金和星云蓝之间过渡。

实现：一个完全独立的 HTML 文件，包含 CSS、JavaScript 和原生 WebGL
着色器。不要外部依赖、外部字体、图片、音频文件或 API Key。图形本身
必须由数学和代码实时生成，不用图片冒充实时渲染。

功能：
1. 48,000 颗拥有固定身份的光点，构成折叠的星之花、扭转引力环和
   旋涡星系。形态切换平滑；连续快速切换时从当前状态接续。
2. 拖动及键盘方向键旋转视角；双击或按钮释放引力，产生先扩散再聚拢
   的绽放。呼吸起伏细腻，不要持续大幅晃动。
3. 生命力和时间流速滑杆；暂停、重置视角、沉浸模式。
4. 可选的 Web Audio 环境音，需用户主动开启；切换形态时平滑换和弦。
5. 导出真正的高清 PNG 纪念海报，包含雕塑、作品名、形态、时间和参数。
6. 支持手机、键盘、可见焦点、减少动态效果、后台停帧和 WebGL 错误提示。

交付完整源码、运行说明、官网嵌入方法、准确的模型参与记录。说明这是
艺术化的数学构造，不是真实物理模拟。不要编造性能结果、测试记录或
one-shot 声明。
```

## 可继续探索

- 将参数曲面换成声波、分形、洛伦兹吸引子或其他原创形态。
- 在用户主动授权麦克风之后，将声音能量映射到粒子的呼吸。
- 让观众为一个瞬间命名，形成个人生成艺术收藏。

这些是后续创意方向，当前作品没有实现麦克风输入或云端收藏。
