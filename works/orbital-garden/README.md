# ORBITAL GARDEN · 轨道花园

> 如果引力也有生命，它会开出怎样的花？

一件可以触摸、暂停和收藏的生成艺术作品。48,000 颗光点组成一朵花、一枚引力环或一座旋涡星系。切换形态时，每颗粒子保留自己的身份，沿连续的路径寻找新的位置；释放引力后，雕塑短暂散开，再重新聚拢。

创作者：[jackroc](https://github.com/jackroc)。创作于 **2026-09-05**，属于可自由探索的交互式粒子艺术沙盒，没有计分或胜负目标。

## 体验

[**点击在线体验 · Open the live demo**](https://orbital-garden.hp20230404.chatgpt.site) — 免费，无需登录或 API Key。

下载并双击 **[index.html](index.html)** 即可运行。全部代码、样式、着色器和声音合成都在一个文件中，无需安装依赖、登录或配置 API Key，也不请求外部字体、图片或音频。

也可以在仓库根目录启动静态服务：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:4173/works/orbital-garden/`。使用支持 WebGL 的现代浏览器；环境音还需要 Web Audio 支持。

## 可以做什么

| 操作 | 结果 |
| --- | --- |
| 点击星之花 / 引力环 / 旋涡星系，或按 `1` / `2` / `3` | 48,000 颗粒子连续变形，同时改变光色和环境音的和弦 |
| 拖动雕塑，或在画布上按方向键 | 旋转视角 |
| 点击「释放一次引力」、双击雕塑，或按 `B` | 粒子扩散、回旋，然后重新聚拢 |
| 调节「生命力」 | 改变呼吸起伏和光点亮度 |
| 调节「时间流速」 | 改变雕塑的动态流速，范围为 0–2 倍 |
| 点击暂停，或按空格 | 暂停 / 继续动画；暂停时仍可旋转、换形和导出 |
| 点击沉浸模式，或按 `F` | 收起文字与控制台，单独欣赏雕塑；按 `Esc` 返回 |
| 点击重置视角，或按 `R` | 回到初始视角 |
| 点击 `SOUND OFF` | 开启实时合成的环境音，再次点击关闭 |
| 点击「收藏这一瞬」 | 下载一张 **2000 × 2400 PNG** 海报，带形态、UTC 时间和参数 |

快捷键在表单、按钮和说明弹窗中让位于原生键盘操作。触屏可横向拖动旋转，纵向滑动保留页面滚动。开启系统「减少动态效果」时，作品默认静止，并关闭绽放效果。

## 展示的能力

- **创意与视觉设计**：将抽象的秩序、混沌和引力转化为可操作的艺术装置，采用展览式排版和中英文文案。
- **数学与图形编程**：原生 WebGL 着色器绘制 48,000 颗发光粒子，用参数曲面构造折叠花瓣、扭转环面和旋臂星系。
- **连续交互**：使用五次平滑插值；在变形过程中再次切换，直接从当前混合位置出发。
- **声音编程**：五个正弦振荡器、低通滤波和低频调制组成环境音，不使用音频素材。
- **完整交付**：响应式布局、键盘操作、减少动态效果、后台停帧、WebGL 丢失恢复与独立海报导出。

这是一种艺术化的引力想象，**不是天体力学或真实流体模拟**。

## 发布到个人官网

将 `index.html` 放到官网静态资源目录即可，例如 `/art/orbital-garden/index.html`。所有资源内联，部署到子目录不需要改路径。建议使用独立页面呈现；也可以嵌入：

```html
<iframe
  src="/art/orbital-garden/"
  title="ORBITAL GARDEN · 轨道花园"
  style="width:100%;height:1100px;border:0;background:#080f12"
  loading="lazy"
></iframe>
```

如官网启用了严格 CSP，需要允许页面内联脚本和样式（可通过计算 hash 配置）；如给 iframe 添加 `sandbox`，需允许脚本及下载才能保留交互和海报导出。

公开演示托管于 [orbital-garden.hp20230404.chatgpt.site](https://orbital-garden.hp20230404.chatgpt.site)。维护部署时，在本目录运行 `node build.mjs`（或 `npm run build`），生成仅包含作品页面的 `dist/`；Sites 配置位于 `.openai/hosting.json`。本地双击运行仍不需要 Node.js。
