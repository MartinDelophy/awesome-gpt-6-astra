# The Road to Kufa — verification and preview source

- Game: [The Road to Kufa](https://road-to-kufa.vercel.app/)
- Creator: [Zenpher](https://www.reddit.com/user/Zenpher/)
- Model evidence: [Reddit](https://www.reddit.com/r/aigamedev/comments/1wc4713/working_on_a_cinematic_game_set_in_arabia/)
- Model role: The creator describes directing Astra to build the procedural Arabian world; a follow-up devlog identifies PlayCanvas and a mix of licensed assets and Astra-generated NPC models.
- Supporting reference: [Playable release and development notes](https://www.reddit.com/r/aigamedev/comments/1weyznt/week_1_of_my_adventure_game_set_in_arabia/)
- Access: Desktop browser; solo mode without sign-in or installation. Initial world loading needed one retry during this check.
- Public counts checked on **2026-09-15**: Creator Reddit devlogs; no comparable view count recorded.
- Play check: The first start failed while loading travelers; Retry followed by another solo start succeeded. Entered as Wanderer, mounted Onyx and used click-to-travel; the region changed from 4 · -3 to 4 · -19 near Medina. Story progression and multiplayer were not tested.
