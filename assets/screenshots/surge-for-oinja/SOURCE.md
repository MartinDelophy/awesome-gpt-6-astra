## Review — 2026-09-28

The demo page and public source README were accessible. The README describes a desktop keyboard game with no installation or account, automatic attacks, two maps and support machines; mobile touch controls are explicitly unsupported. The submitter additionally states no API key is required.

Olivia attributes iterative code/system development in Codex to GPT-6 Astra, including combat, synergies, procedural environments, UI and debugging. Original Oinja characters/world, creative direction and playtesting are the creator's work. This is a creator statement, not an independent development audit.

No interactive browser was available for this review. Actual movement, combat and completion were not independently tested; a successful page request is not a playthrough.
