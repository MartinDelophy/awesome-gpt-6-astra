## Browser verification — 2026-09-12

Opened the direct game in a desktop browser without signing in, paying, downloading or installing anything. The menu lists Brindle Bay, The Old Sound and Lantern Reach. Selecting “Let’s cast off” entered the first salvage voyage, with Mallow, floating cargo, a harbour crane, delivery objective, hull status, boost meter and steering/hook/release/repair controls visible. The interface advertises progress saved on this device. This check establishes access and a running first voyage; it does not verify all deliveries, later voyages, save restoration or physical phone play.

The creator reports iterative development using GPT-6 Astra in Codex for the Canvas game, towing physics, crane delivery, interface, weather and audio, with personal design direction and playtesting. Image generation supplied art separately; Web Audio synthesis supplies music and sound effects. The statement is not an independent audit of model usage and does not claim a one-prompt build. The creator identifies vanilla JavaScript, Canvas 2D, Vite and Web Audio; the source repository is private. The separate itch.io edition allows optional support ($1 suggested), while play is free.
