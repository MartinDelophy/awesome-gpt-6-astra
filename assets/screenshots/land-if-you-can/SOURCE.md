# Land, If You Can — verification and preview source

- Game: [Land, If You Can](https://landifyoucan.naylalabs.xyz/)
- Creator: [Taniai_](https://www.reddit.com/user/Taniai_/)
- Model evidence: [Reddit](https://www.reddit.com/r/TurkOyunSektoru/comments/1w96dlh/herkes_gpt_6_astra_ile_bir_%C5%9Feyler_payla%C5%9F%C4%B1yordu/)
- Model role: The creator says Astra used Godot 4 and Blender to build the landing simulation, iterating on mechanics, scenery and replays through roughly 30 prompts.
- Access: Desktop browser with mouse and keyboard; free, no sign-in or installation. Initial asset loading takes time; flight replays are shared automatically.
- Public counts checked on **2026-09-15**: Creator Reddit release post; no comparable view count recorded.
- Play check: Started Cabin Fever and stood up with E, then used the menu's Skip to Jet Cockpit shortcut, contacted the tower with R and took manual control with P. The cockpit displayed 200 knots, 3,000 feet and live navigation. No landing was completed.
